# Установка hrneo из этого фида на Keenetic

Форк [HydraRoute Neo](https://github.com/Ground-Zerro/HydraRoute) с защитой от утечек. Трафик к адресам из списков HydraRoute получает метку политики ещё в таблице `raw`. Поэтому он не уходит через провайдера, пока Keenetic пересобирает iptables (продление DHCP, смена WAN), пока hrneo перезапускается или упал. Когда туннель лежит, такой трафик блокируется.

Форк заменяет только демон `hrneo`. Веб-панель HydraRoute (hrweb), ваши списки и настройки остаются прежними.

## Что нужно

1. **Keenetic с Entware.** В системе должен быть установлен компонент «Поддержка открытых пакетов» (OPKG), а Entware — развёрнут на USB-накопителе. Доступ по SSH к Entware: обычно `ssh root@<роутер> -p 222`.
2. **Архитектура `aarch64-3.10`.** Проверка на роутере:

   ```sh
   opkg print-architecture | grep aarch64-3.10
   ```

   Если строки нет (например, на mipsel-моделях `mipselsf-k3.4`), этот фид пока не подходит: сборки для MIPS ещё нет.
3. **HydraRoute Neo уже установлен и настроен** по [инструкции апстрима](https://github.com/Ground-Zerro/HydraRoute). Нужны веб-панель, политика с туннелем и ваши списки доменов и IP. Сначала добейтесь, чтобы обычный HydraRoute работал, потом переходите на форк.
4. **`curl` или `wget` с HTTPS.** Если нет ни того, ни другого, выполните `opkg install curl`.

## Установка и обновление

На роутере, в оболочке Entware:

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
curl -fsSL https://raw.githubusercontent.com/le0nus/hydraroute-release/main/keenetic/install-feed.sh | sh
```

Установщик делает следующее:

- добавляет фид `le0nus-hr` в `/opt/etc/opkg/customfeeds.conf` (старая строка этого же фида, если была, заменяется);
- скачивает пакет и ставит его, только если размер и SHA256 совпадают с индексом фида;
- проверяет, что opkg показывает пакет полностью установленным;
- ставит `hold`, чтобы `opkg upgrade` не вернул версию апстрима.

Тот же скрипт:

- **обновляет** до новой версии форка — достаточно запустить его ещё раз;
- **доводит** прерванную установку;
- **никогда не понижает** версию.

Во время установки hrneo перезапускается. Живые соединения к сервисам из списков на 1–3 секунды обрываются, потом переподключаются.

## Проверка

```sh
hrneo --version                      # hrneo v3.21.0-1le2
opkg status hrneo | grep Status      # Status: install hold installed
cat /var/run/hrneo-status            # raw_guard=on, policy.<имя>.v4=ok
iptables -w -t raw -S PREROUTING     # первым стоит -A PREROUTING -j HRNEO_GUARD
```

`raw_guard=degraded:<причина>` означает, что защита не подтверждена. Причину смотрите в журнале: `ndmc -c "show log" | grep hrneo`.

## Совет: закрепите важные диапазоны

Адреса из DNS попадают в список только тогда, когда через роутер проходит DNS-ответ, и живут в нём `IpsetTimeout` секунд (по умолчанию 6 часов). Для критичных сервисов надёжнее закрепить их собственные диапазоны в `/opt/etc/HydraRoute/ip.list`. Например, для Anthropic (Claude):

```text
##CIDR: Anthropic (pinned)
/HydraRoute
160.79.104.0/21
```

Здесь `/HydraRoute` — имя вашей политики. После правки перезапустите hrneo: `neo restart`. Перезапуск на секунду рвёт соединения.

## Полезные команды

| Команда | Что делает |
|---|---|
| `neo restart` | перезапуск hrneo |
| `neo ipset-clean` | очистить списки адресов и загрузить их заново (адреса из DNS вернутся по мере запросов) |
| `neo raw-off` | остановить hrneo и снять защиту `raw` (нужно перед откатом на старую версию) |

## Откат на старую версию

Сначала снимите защиту. Старый hrneo без неё может пропускать трафик мимо туннеля.

1. Выполните `neo raw-off`. Продолжайте, только если команда завершилась кодом 0 или 3.
2. Убедитесь, что ни `iptables -w -t raw -S`, ни `ip6tables -w -t raw -S` не показывают `HRNEO_GUARD`.
3. Поставьте нужную версию:

   ```sh
   opkg flag user hrneo
   opkg install --force-downgrade <файл .ipk>
   opkg flag hold hrneo
   ```

Старые пакеты лежат в `keenetic/aarch64-k3.10/` этого репозитория.

## Удаление

`opkg remove hrneo` сам останавливает демон и снимает защиту `raw`. После этого можно вернуть hrneo из апстрима.
